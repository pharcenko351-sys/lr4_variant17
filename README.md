# Програмний проєкт №4, варіант 17

Харченко Поліна, група К-28.

## Завдання

Багатопотокова структура даних з m = 2 цілих полів. Частки операцій від усіх:

| | read | write |
|---|---|---|
| Поле 0 | 5% | 5% |
| Поле 1 | 30% | 5% |
| string | 55% | |

## Файли

- `data.h`, `data.cpp` -структура `Data`: `get(i)`, `set(i, value)`, `operator string`.
- `program.cpp` - main.
- `config.h` - кількість операцій, повторів і три послідовності дій.
- `generator.h`, `generator.cpp` - створення тестових файлів.
- `ops.h`, `ops.cpp` - зчитування дій з файлу.
- `runner.h`, `runner.cpp` - виконання дій у потоках і вимірювання часу.
- `CMakeLists.txt` -збірка проєкту.
- `report.pdf` -звіт.

## Схема захисту

Один `std::mutex` захищає всю структуру. Операції `get` і `set` тримають його лише на час одного звернення до поля. Операція `string` копіює два числа під м’ютексом, а форматування рядка виконує після його звільнення.

Більшість операцій (55%) - це запит рядка, який читає обидва поля одразу. Тому поки він виконується до обох полів ніхто інший не звертається.Взято один м’ютекс на всю структуру, бо це простіше і дає гарну швидкістю.

## Тестові файли

Програма сама створює папку `tests` з файлами у форматі:

```
write 1 1
read 1
string
```

Три послідовності дій: `a` (частоти за умовою), `b` (усі частоти по 20%), `c` (read0 2%, write0 60%, read1 3%, write1 30%, string 5%). Для кожної послідовності створюється 6 файлів по 400 000 дій. 1 потік виконує всі 6 файлів, 2 потоки - по 3, 3 потоки -по 2, тому загальна кількість дій (2 400 000) однакова. Час зчитування файлів не вимірюється. Кожен вимір повторюється 5 разів, у кінці виводиться таблиця середніх часів 3×3.

## Збірка та запуск

Компілятор з підтримкою C++20.У PowerShell:
```
cd lr4_variant17
g++ -std=c++20 -O3 -pthread program.cpp data.cpp generator.cpp ops.cpp runner.cpp -o p4
./p4
```
Через CMake:

```
cmake -S . -B build
cmake --build build
```
